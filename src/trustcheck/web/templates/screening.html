How Screening Works

Our screening engine uses multiple algorithms to find potential matches:

  • Exact matching - Direct name comparison
  • Fuzzy matching - Catches typos and variations
  • Phonetic matching - Finds names that sound similar (Mohammad/Mohammed)
  • Token matching - Handles name order differences

The match score indicates the confidence level of the match. Higher scores indicate stronger matches.
